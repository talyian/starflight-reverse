HEAD: SCAN-CREW-STATS ( n -- [iaddr] f )
T: >R *ASSIGN-CREW >C+S
 0 6 0 DO CAPTAIN I 3 * + 1.5@ >C+S ^STA @ J AND
   IF 1+ >R CI R> LEAVE THEN ICLOSE
 LOOP ICLOSE R> DROP T;

HEAD: .VITALS ( n -- )
T: >R I 0= IF ." DEAD" ELSE
      I  1 21 WITHIN IF ." CRITICALLY" ELSE
        I 21 51 WITHIN IF ." HEAVILY" ELSE
          I 51 81 WITHIN IF ." MODERATELY" ELSE
            I 81 100 WITHIN IF ." SLIGHTLY" ELSE ." NOT"
 THEN THEN THEN THEN ."  WOUNDED" THEN R> DROP T;

HEAD: >TREAT ( iaddr -- )
T: >C+S ^VIT C@ 1 100 WITHIN

HEAD: GET-CREWMEMBER ( f -- iaddr )
T: CTERASE ." WHO SHOULD I " .T/X ." ?"
 *ASSIGN-CREW >C+S
 1 38 CMESS ." CHOOSE CREWMEMBER ^\ AND PRESS BUTTON" !CRS
 CAPTAIN 1.5@ >C+S 11 2 CTPOS. ^NAME $. ICLOSE
 0 BEGIN XYSCAN DROP ?DUP
   IF + 6 MOD DUP 0< 6 * + DUP 3 * CAPTAIN + 1.5@ >C+S
   11 2 CTPOS. 15 BLACK POLY-ERASE-TEXT ^NAME $. ICLOSE THEN
 ?TRIG UNTIL 3 * CAPTAIN + 1.5@ ICLOSE T;

 ICLOSE T;
