: >RCOLOR ( addr -- )
 C@ IF B-TABLE ELSE E-TABLE THEN 0 3 RRND + C@ !COLOR ;

: RSHAPE ( addr -- x y )
 >R I 1+ C@
 IF 0 I 4 + C@ 1+ RRND I 4 + C@ DUP *
   OVER DUP * - 0 SQRT 1+ 0 SWAP RRND
   0 2 RRND IF NEGATE THEN >R
   0 2 RRND IF NEGATE THEN    2/   I' 2+ C@ + R> I 3 + C@ +
 ELSE
   I 2+ C@ I 4 + C@ 1+ RRND I 5 + C@ I 3 + C@ 1+ RRND
 THEN R> DROP ;
