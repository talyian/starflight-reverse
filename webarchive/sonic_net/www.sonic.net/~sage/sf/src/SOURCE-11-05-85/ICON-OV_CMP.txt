---- Screen 13 ----
( ICONP-OV   #ID-PLAYER #ID-ALIEN                      3-15-85)

HEAD: #ID-PLAYER ( -- id \ find right blt for player's ship)
  ( based on heading)
T:  %HEADING C@ 27 + T;

HEAD: #ID-ALIEN ( -- id \ find right blt for alien ship )
  ( based on heading)
T:  VES-DIRECTIONAL C@
  IF   VES-HEADING C@ 35 +
  ELSE 43 ( non-directional icon#)
  THEN T;

( ICONP-OV   STAR-ID-CASES #ID-STAR                    3-05-85)

CASE STAR-ID-CASES ( n -- blt#)
\  1 IS ID-STAR-ORBIT   ( orbit level)
   2 IS ID-STAR-SYSLVL ( system level)
\  4 IS ID-STAR-ORBIT   ( encounter in orbit)
OTHERS ID-STAR-ORBIT \ UNRAVEL

HEAD: #ID-STAR ( -- icon#\ set blt# )
  ( based on context ie. either )
  ( at system level or in encounter.)
T:  CONTEXT-ID# @  STAR-ID-CASES T;

  ( motion & type)
