\ delta-xy                                          (rfg11oct85)
\ x,y are the moving coordinates, x1,y1 are fixed

: rdit begin -1 2 rrnd ?dup until ;

: delta-xy \ x,y x1,y1 --- x,y deltax,deltay
 2over 2over d=
  if 2drop 0. \ rdit rdit \ force movement in case same points
  else  2over  rot swap - dup
       if dup abs / then >r
        - dup
       if dup abs / then r>
  then ;
