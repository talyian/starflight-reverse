( COMBLT - .HYBRID                                     9-12-85)

: .HYBRID ( seg -- \ plot a hybrid packed blt at seg: assumes)
  ( xblt, yblt are set)
  DUP BLTSEG ! >R  5 ABLT !
  I 2 LC@ LBLT !  I 3 LC@ WBLT !
  R> 4 LC@ 0 DO ABLT @ >R BLTSEG @ >R  4 ABLT +!
                I I' 2+ LC@ COLOR !  R> R> 3 + LC@
                IF   BLTSEG @ ABLT @ .RUNBIT
                ELSE (BLT)
                THEN
                BLTSEG @ ABLT @ 4 - L@ 4 - ABLT +!
             LOOP ;

: PIC>PAD ( file# -- )  PAD ADDR>SEG 1+ SWAP FILE< ;
